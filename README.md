# co2-lab/scoop-bucket

Bucket [Scoop](https://scoop.sh) do co2lab. Os manifestos em `bucket/` são **gerados pelo
goreleaser** a cada release — não edite à mão.

## Instalar

```powershell
scoop bucket add co2lab https://github.com/co2-lab/scoop-bucket
scoop install anchors
```

## O que há aqui

| pacote | o que é |
| --- | --- |
| [anchors](https://github.com/co2-lab/anchors) | framework spec-first de continuidade para desenvolvimento assistido por IA |
